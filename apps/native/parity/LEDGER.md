# Native parity ledger

One row per user-facing capability of the web client. `parity/sync.ts` matches every upstream
change against **Web source** (repo-relative files or directory prefixes; the longest match
wins), so keep those paths accurate when you split or move a row.

- **Status**: `done` (matches web behavior), `partial` (usable, gaps noted in the issue),
  `todo`, `n/a` (deliberately not ported: say why in Feature).
- **Native**: path under `apps/native/` that owns it.
- **Issue**: the fork issue tracking remaining work.

Rows marked `[D]` are desktop-only in the web build (Electron); the native app is a desktop
app, so most of them apply here too.
